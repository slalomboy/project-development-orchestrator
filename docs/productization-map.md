# 项目安排与交付成品能力地图

[English](en/productization-map.md) · [返回中文首页](../README.md)

| ID | 完整用户结果 | 最低输入 → 输出 | 免费领取物 | 付费升级 |
|---|---|---|---|---|
| `FIN-PM-000` | 从模糊需求到验证、版本、回滚和复盘的项目控制面 | 项目目标、现状、约束和授权 → 项目事实、计划、状态、验证与交付证据 | 项目从需求到交付全流程地图 | PD 模板、案例、质量门和恢复体系 |
| `FIN-PM-001` | 可执行需求 Brief 与规格 | 原始需求、现状和限制 → 六字段 Brief、验收和待确认项 | 项目需求六字段澄清卡 | PD 规格追溯与变更管理 |
| `FIN-PM-002` | 带依赖和验收映射的执行计划 | 已确认范围/规格 → 阶段、任务、负责人、依赖、测试与停止条件 | 项目任务拆解与验收映射表 | PD 并发、写锁、进度和组合管理 |
| `FIN-PM-003` | 分层验收报告与缺口 | 验收标准、产物和运行证据 → 六真相面结论与最高已证明状态 | 六个交付真相面验收表 | PD 自动检查、失败回放和客户验收包 |
| `FIN-PM-004` | 可追溯、可恢复的版本交付记录 | 已验证源码/产物、版本策略和授权 → 版本、Tag/Release事实、兼容和回滚路径 | 版本与交付追溯清单 | PD 更新包、平台矩阵和回滚演练 |

四个单项可以单独使用，也可以通过 `FIN-PM-000` 串成完整体系。外部发布、部署、推送和权限动作不是这些模板自动授予的能力。
