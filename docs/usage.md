# 使用说明

[English](en/usage.md) · [返回首页](../README.md)

最小输入是问题、用户、成功路径、首版必需项、排除项和约束。先选 `lightweight`、`standard` 或 `full` 风险档位，再进入 intake、discovery、specification、design、planning、implementation、verification、release 和 operate 生命周期。

每次变更都要记录目标、范围、排除项、风险、版本影响、验收和回滚。外部动作必须单独标授权；失败时退回拥有缺陷的阶段，不靠改状态名称绕过质量门。
