# Changelog

All notable changes to this Skill are recorded here.

## [0.5.0-alpha.1] - 2026-08-11

### Added

- Restored the independently useful public Skill with its real lifecycle implementation, templates, state validator, and 15 tests.
- Added bilingual public documentation and productization mapping for `FIN-PM-000` through `FIN-PM-004`.

### Changed

- Replaced the deprecation-only main branch with a public-lightweight, private-context-free implementation.
- Kept deployment, publication, pushes, permissions, production data, and destructive actions behind explicit authorization.

### Boundaries

- No customer data, private roles, internal project records, credentials, machine paths, GitHub Release, or repository visibility change.

## [0.5.0] - 2026-08-01

### Added

- Added Dalin AI Works reusable lifecycle gates for vertical slices, bounded `lightweight` validation promotion, Current authority and long-running operation contracts.
- Added a product-grade UI design gate covering information architecture, page-state matrices, three materially distinct visual directions, target selection, design contracts and real-shell evidence.
- Added six parallel delivery-truth surfaces with minimum evidence for source, candidates, installed applications, platform trust, Git/Release assets and customer distribution.
- Added reusable failure-pattern, new-project delivery and UI design templates.

### Changed

- Project-grade UI work now enters implementation only after an accepted visual target; canonical `lightweight` validation keeps a bounded exception.
- Completion and release conclusions now use the weakest required delivery-truth surface and cannot be upgraded by risk acceptance alone.

### Compatibility

- Backward compatible with 0.4.x project modes, profiles, lifecycle stages, templates, multi-agent routing and `project-state.json` schema.

## [0.4.0] - 2026-07-14

### Added

- Added bounded multi-agent routing with current-task and standing authorization models.
- Added eligibility, quota, capacity, ownership, delegation-contract, downgrade, integration, and planning-record gates.

### Changed

- Project plans now record a multi-agent and quota decision when delegation is relevant.
- Superpowers delegation methods now defer to the orchestrator's quota-aware multi-agent control plane.

### Compatibility

- Backward compatible with 0.3.x project modes, lifecycle stages, templates and `project-state.json` schema.

## [0.3.0] - 2026-07-14

### Added

- Added explicit routing for all 14 Superpowers 6.1.1 Skills as a conditional development-method layer.
- Added delegation, artifact-location and control-plane precedence rules.

### Changed

- Kept `project-development-orchestrator` as the sole lifecycle control plane while allowing stage-appropriate Superpowers methods.
- Clarified that pure Q&A, translation, chat, one-off copy and read-only reporting do not enter a Superpowers development workflow by default.

### Compatibility

- Backward compatible with 0.2.x project modes, profiles, lifecycle stages, templates and `project-state.json` schema.
