# 项目开发总控：停止作为公开 Skill

[中文](README.md) | [English](README_EN.md)

本仓库不再提供可安装或可调用的 Skill。原公开版本只有项目生命周期路由和授权原则；离开内部 AGENTS、版本治理、专业执行 Skill、项目状态和审批链后，不能独立完成项目接管、开发、验证或交付。

## 停止公开原因

“管理整套项目”不是可独立领取的单一结果。原包没有交付真相检查器、Release 追溯工具、多平台版本矩阵、需求澄清模板或真实项目回放，却把内部总控包装成独立 Skill，未通过独立价值门。

## 当前状态

- 当前固定 Tag：[`v0.2.0-alpha.1`](https://github.com/slalomboy/project-development-orchestrator/tree/v0.2.0-alpha.1)。
- 状态：`DEPRECATED_PUBLIC_SKILL_BODY_REMOVED`。
- 当前 `main` 不含 `SKILL.md`，不提供安装或调用路径。
- 仓库、PUBLIC 可见性、Apache-2.0 许可证和历史 Tag 保持不变；没有创建 Release。

## 历史恢复

旧公开轻量包保留在 [`v0.1.0-alpha.1`](https://github.com/slalomboy/project-development-orchestrator/tree/v0.1.0-alpha.1)，仅供审计、差异比较和恢复，不再推荐安装。

## 限制

- 当前不能接管、开发、测试、发布或部署任何项目。
- 不提供权限、版本、状态或外部动作判断服务。
- 未来只能把具有具体输入输出和真实回放的原子工具重新提交公开评审，不能恢复“总控即产品”的表达。
